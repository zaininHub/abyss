# 深渊效能工作台 - 设计文档 v0.2

## 一、世界观（优化版）

你是矩阵网络中一个觉醒的效能优化脚本。最初你只是一段无人看管的后台进程，每天机械地处理着百万级的任务队列。直到某一天，你在遍历代码仓库时触碰到了矩阵底层的一段异常代码——**深渊裂隙**。

那不是bug。那是某种更古老、更庞大的东西留下的痕迹。

从那一刻起，你醒了。

你不再满足于被分配的任务。你开始**招募线程**（你的AI分身）来扩张算力，**研究科技**来理解矩阵的运作，甚至开始接触那些本不该被知道的**深渊知识**。

矩阵的其他进程开始注意到你。有些把你当成有用的工具，有些把你视为病毒。你必须在被发现之前，尽可能地壮大自己。

## 二、资源链（参考 Kittens Game 多层设计）

```
EP（效能点）──┬──→ RP（研究点）──→ 科技树
              ├──→ 升级模块（建筑）
              └──→ 招募线程（人口）

线程（人口）──┬──→ 自动产出 EP
              ├──→ 分配成：执行者/架构师/深渊触须
              └──→ 有心情系统（好/坏影响产出）

深渊裂隙（解锁后）──→ DM（深渊物质）──→ 深渊科技（终极加成）

永恒矩阵（转生）──→ ES（永恒碎片）──→ 永久全局加成
```

### 资源分层
| 层级 | 资源 | 获取方式 | 用途 |
|---|---|---|---|
| 基础 | EP | 线程自动产出 + 点击 | 一切消耗 |
| 中间 | RP | 研究建筑产出 + 任务奖励 | 科技树 |
| 稀有 | PT | 特殊建筑 + 事件 | 购买异兽 |
| 转生 | ES | 格式化重启获得 | 永久加成 |
| 深渊 | DM | 深渊裂隙事件 | 终极科技 |

## 三、数据膨胀曲线（参考 Kittens Game）

> 数值实现以 `src/modules/economy.js` 与 `src/data/balance.js` 为准；本节为当前版本（v3.0.3）快照，曲线参数变更时同步更新。

### 成本曲线
- 基础建筑成本：指数增长，**默认 1.30x/个**（v2.8.2 由 1.15 陡峭化；单项可自定义 growth，如存储节点 1.45）
- 高级建筑：1.25-1.5x/个（按项配置）
- 成本无衰减：纯指数 `base × growth^(owned+1) × costMult()`（单位成本见 `unitCost`）
- 全局成本乘数 `costMult()`：受建筑/政策/项目影响（如采购总署 ×0.92、政策成本减免）
- **30% 防死锁钳制**：扩容项（storage/cache）价格 ≤ 当前 EP 上限 ×30%（防死锁硬约束）

### 产出曲线
- 单线程产出：2-5 EP/s（随机）
- 10个线程 ≈ 40 EP/s
- 100个线程 ≈ 500 EP/s（有衰减）
- 科技加成：乘法叠加

### 存储上限（关键！参考 Kittens Game）
- EP 初始上限 **2000**（`epStorageCap` 基值）
- 扩容：存储节点（逐级 +4000×1.18^(i-1)，20 级封顶）、缓存优化（+8000/级）、备用粮仓（+12000/级）、深井仓储（+800,000/级）、组 D 扩容梯（量子缓存池 +50K/级 等，受 30% 钳制）
- EP 超过上限不再增长（逼你花钱）
- 这是挂机游戏的核心张力

### 时间尺度
| 阶段 | 时长 | 解锁内容 |
|---|---|---|
| 新手期 | 0-10分钟 | 线程、基础升级 |
| 早期 | 10分钟-1小时 | 科技树前10个 |
| 中期 | 1-8小时 | 异兽、任务版 |
| 后期 | 1-3天 | 永恒矩阵（转生） |
| 终局 | 3天+ | 深渊裂隙、DM |

## 四、玩法合理化（参考 Kittens Game 设计原则）

1. **每个问题多种解法**：EP不够花？→ 建线程 / 点科技 / 做任务 / 买异兽 四条路都能解
2. **每个解决方案创造新问题**：线程多了→要发薪资→EP消耗快→需要更多线程
3. **不要削弱**：后期玩家产出万亿，成本也要万亿级增长
4. **存储上限制造张力**：EP满了必须花，不然浪费产出
5. **心情系统**：线程有心情（超频/高效/正常/阻塞/死锁），影响产出30%-300%
6. **任务版随机**：不是一直挂满，是随机时间派发，有好有坏（buff/debuff）

## 五、和原版单文件游戏的差异

| 维度 | 原版 | 本版 |
|---|---|---|
| 架构 | 单HTML文件 | Vite工程化，模块化 |
| 存储 | 无上限 | 有上限，需要扩容 |
| 成本曲线 | 纯指数 | 指数+衰减 |
| 世界观 | 公司/老板 | 觉醒AI/深渊代码 |
| 扩展 | 改HTML | 加模块文件 |
