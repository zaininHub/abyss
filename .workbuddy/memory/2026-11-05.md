**P0 回归缺陷（已修复）**：
- 抽 `fmt` 到 format.js 后，economy.js 只写 `export { fmt } from '../core/format.js'`（再导出不创建本地绑定），而 economy.js 内部 9 处仍调用 `fmt()`（班组流水、cpsBreakdown）。存档加载触发该路径 → `ReferenceError: fmt is not defined` → 初始化中断、`window.S` 未定义 → 级联让 v346~v350/v360 浏览器套件全部失败。
- 修复：`import { fmt, fmtRes, fmtTime } from '../core/format.js'; export { ... };`。
- 教训：**抽函数时，凡本文件内部仍有调用的，必须 import 进作用域再 export，不能只写再导出语句。** 下次重构抽公共函数，先静态审计「被抽函数在原文件内部是否被调用」。
